Production checklist

Verify, don’t just publish

  • Open each deployed URL over HTTPS and test it at desktop and mobile widths.
  • Reload a nested route directly; confirm that the host serves the intended page.
  • Check keyboard access, semantic landmarks, useful alternative text, and color contrast.
  • Trigger a missing route and confirm the recovery page points visitors back to working content.
