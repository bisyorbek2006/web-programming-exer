Week 9.1 Exercise 1

Week 9.1 · Keyboard access

Fix the button

The goal is to replace a non-semantic element with a real button and make the keyboard focus easy to see.

Requirements:
  1. Use a real <button type="button"> instead of a div
  2. Add a clear focus state using :focus-visible
  3. Give the close icon a proper accessible name with aria-label

Try pressing Tab and then Enter to test the controls.
