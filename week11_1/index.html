Homework 1 · Student profile card

A directory powered by props

Create a Vite + React app with a reusable StudentProfileCard that accepts a name, student ID, major, year, and GPA. Render several profiles from data rather than duplicating the markup.

function StudentProfileCard({ name, studentId, major, year, gpa }) {
  return (
    <article className="profile-card">
      <p>{studentId}</p>
      <h2>{name}</h2>
      <p>{major} · Year {year}</p>
      <p>GPA {gpa}</p>
    </article>
  );
}

Build goal: keep the card presentational, provide its data as props, and map a student array using a stable unique key.
